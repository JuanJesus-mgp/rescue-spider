# Índice de Documentación Técnica - Rescue Spider

Esta carpeta contiene la documentación oficial del robot cuadrúpedo autónomo:

- **`/architecture`**: Diagramas de bloques, asignación de pines del ESP32 y arquitectura de software.
- **`/hardware`**: Esquemáticos de potencia, diagramas de conexión (PCA9685, LM2596, VL53L0X, INMP441) y GND común.
- **`/roadmap`**: Planificación Agile, definición de Sprints e hitos de avance.
- **`/manuals`**: Datasheets y notas de calibración de componentes.
